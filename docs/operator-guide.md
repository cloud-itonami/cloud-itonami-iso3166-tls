# Operator Guide

## First Deployment

1. Confirm the client's incorporation/legal-entity status is complete
   (route to `cloud-itonami-M6910` or local counsel first if not).
2. Register the client's intake: business type, target public
   function, prior filing history in Timor-Leste if any.
3. Run the advisor in read-only mode against the Aprovisionamento
   (public procurement) regime (Decreto-Lei n.º 10/2005, as amended)
   and SERVE's own commercial-registration requirements (Decreto-Lei
   n.º 16/2017).
4. Compare the checklist against the client's current documentation.
5. If the client intends to use Decreto-Lei n.º 2/2010's decentralized
   local-works procurement track, confirm the underlying tender value
   is within the $250,000 ceiling and that the client has not been
   sanctioned for fraud or corruption BEFORE drafting — the governor
   will hold either violation as a HARD, unoverridable stop.
6. Enable gated filing-draft assistance once the Market-Entry
   Compliance Governor contract is trusted; actual submission always
   requires human sign-off.

## Minimum Production Controls

- client-owned data store for business/tax registration documents
- clear provenance (official portal/regulation citation) for every
  requirement surfaced
- approval workflow for any portal registration or filing submission
- named referral relationship with Timor-Leste-licensed counsel or a
  registered agent for anything beyond checklist/draft assistance
- monthly audit export

## Known Coverage Gap

This actor's `statute.facts` catalog does NOT yet include a labor-law
citation for Timor-Leste — this is a disclosed research gap (see
`src/statute/facts.cljk`'s namespace docstring), not an oversight.
Operators advising on labor-law compliance specifically should route
to Timor-Leste-licensed counsel until a verified primary-source
citation can be added.

## Certification

Certified operators must prove data provenance, audit traceability, that
automated actions cannot bypass the Market-Entry Compliance Governor, and
a working referral relationship with Timor-Leste-licensed counsel or a
registered agent for whatever licensed representation the law of
Timor-Leste requires for actual public-procurement filings.
